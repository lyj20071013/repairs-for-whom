# Analysis plan

`论文方案.md` is an exact byte copy of the cumulative Chinese research plan as available on 2026-11-13 (previous release: 2026-10-28; the earlier version is in Git history). It includes dated designs, gates, amendments, outcomes and exploratory follow-ups. Read each section's status rather than treating every section as a confirmatory prediction.

Key sections: 6.1 (gridworld confirmation), 6.3 (ALFWorld feasibility/screened pool), 6.6 (screen-then-rollout), 6.7–6.8 (exploratory consequences/shared repairs), 6.9 (unscreened Qwen7B ALFWorld), 6.10 (second deployed executor), 6.11 (human study draft), 6.12 (follow-ups and independent preference checks, including G), 6.13 (WebShop), 6.14 (τ²-bench shared pool, including amendments 1–4).

`amendments_202611/` holds the dated notes written as separate files in November 2026: amendment 5 to 6.14 (handling of missing rollouts), the registration of the policy-difference/loss analysis (H1/H2 on τ²-bench), the definition of the post hoc headroom and reliability analyses, and the result note for the τ²-bench shared pool. Registrations of the successor-training and τ²-bench training studies are kept with their code in `followup/` (see `followup/README.md`).

Recorded dates come from the authors' working log. This repository release is not an independent public timestamp for those earlier dates. Human annotation data are not included in this release. Original comments and historical local paths are preserved as research provenance, not current installation instructions.
