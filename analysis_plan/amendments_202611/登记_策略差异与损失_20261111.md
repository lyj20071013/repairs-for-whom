## 2. 假设
| 编号 | 打标签者 A → 执行者 B | 假设（单侧） |
|---|---|---|
| H1 | 4B → 2B | 位置层面 Spearman ρ(D, L) > 0 |

预测：H1 把握中等偏低，H2 较低。理由见第 6 节的两个已知不利因素。

## 3. 定义
**位置**：`out_tau_pool/design_p4sub.jsonl` 的 201 个位置（96 个任务）。**分支** = 原动作 + v3 可执行的替代候选（不含自由选择、随机）；至少 2 个分支才合格（预计 200 个）。还要求：2B 每个分支 ≥ 8 次有效续跑、4B ≥ 5 次、两个模型每一半 ≥ 15 个第一步样本。奖励用 `score = orig_task`。

**动作键**
- 主定义：工具调用 = `pool_tau2.canon` 的"工具名(按键排序的参数)"，整串转小写；文字回复 = 27B 盲判的类别 A–G（`classify_drift.py`，提示与类别同第 6 篇补充五，不改）。
- 改动理由：按草稿把文字合成一类时，4B 在 67% 的位置上 20 个样本只有一种动作，27% 的位置全是文字；D 会大量并列在 0。

**D（H1）**：每个模型 4 组 × 10 个第一步样本（温度 0.7、关思考，同池续跑）；半 1 = 第 1、2 组，半 2 = 第 3、4 组。
D = ½[TV(A¹, B¹) + TV(A², B²)] − ½[TV(A¹, A²) + TV(B¹, B²)]。4B 的第 1、2 组用已有的 `pool/drift.jsonl`（11-07 采，同一设置），第 3、4 组新采。
**D（H2）**：1 − 2B 的 40 个样本中动作键等于贪心动作 g 的比例；g = 2B 在该位置温度 0 采的 1 个第一步（子集设计里没有自由选择分支，所以新采）。

**L**（执行者 2B）：每个分支的 2B 续跑随机分成两半（选择 / 评价），重复 50 次，种子 sha256("H1H2|" + 位置 id)。每次 L_s = 评价折(a\*₂B) − 评价折(a\*_A)，对 50 次取平均。
- a\*₂B：选择折均值最高的分支；a\*_A：H1 用 4B 全部续跑的均值最高者（不划分），H2 用 2B 贪心那 1 次结果最高者。
- 并列时取并列分支的平均（均匀随机打破平局的期望）。这与 P2τ 不同：P2τ 的单位是轨迹、用随机数流打破平局，位置层面没法照搬。

## 4. 新增数据（`run_first_p4.sh`；不读任何 reward）
201 个位置：2B 40 个 + 温度 0 的 1 个；4B 新增 20 个；文字回复交 27B 分类。约 12,300 次单步生成加几千次分类，粗估 < 1 卡时。

## 5. 检验与解读
- 统计量：合格位置上的 Spearman ρ(D, L)。按任务成簇、按领域分层的 bootstrap 10,000 次（种子 0）；p = (#{ρ\* ≤ 0} + 1) / (B + 1)；Holm m = 2，校正后 < 0.05 成立。
- 效应大小（描述）：D 最高与最低三分之一位置的平均 L 之差。
- **L 的可靠性**（新增）：只用第 0–4 次续跑算一个 L，只用第 5–9 次算另一个（各自 3 选 2 评的全部划分），报告两者的 Spearman。**低于 0.20 时，阴性结果写"L 在位置层面不可靠，不足以判断"，不写"不存在关系"**。
- 敏感性（不改判定）：(a) 控制 2B 第一步动作的熵；(b) 只按工具名；(c) 不减噪声底；(d) 控制 2B 选择折上分支均值的极差（候选之间没有差别的位置 L 必为 0）；(e) 文字合成一类（草稿的原定义）。

| 结果 | 怎么写 |
|---|---|
| H1 成立，(a)、(d) 同号且量级相近 | 正文：τ² 上位置层面的策略差异能预测按另一个模型选修复的损失 |
| H1 成立，但 (a) 或 (d) 接近 0 | 关联来自 2B 自身的不确定性或候选的差距，不是错配；只进附录 |
| H1 不成立，L 可靠性 ≥ 0.20 | 不主张"差异预测损失"；正文主结论仍是 P2τ |
| H1 不成立，L 可靠性 < 0.20 | 不足以判断 |
| H2 | 单独报告，只限"多次采样 vs 一次贪心" |

## 6. 事先写明的不利因素
1. **模型对层面已有反例**：ALFWorld 上 π0 → S11 / S12 的第一步 TV 是 0.80（噪声底 0.19），按 π0 的选择给后继用的损失是 −0.002 / −0.012；同一环境 7B ← 14B 的损失是 0.29。所以"差异大 ⇒ 损失大"在模型对层面不成立。E1 / E4 的图必须画出这个点；正文的说法至多是"差异是损失的必要条件而非充分条件"，除非 H1 及 (a)、(d) 都成立。
2. **L 可能大半是噪声**：4B 在本池上 3 次续跑选出的修复在另一半只多 +0.10，标签一半不可重复（11-10 事后分析）；4B 每分支只有 6 次，a\*₄B 并列多。功效会明显低于按 200 个位置估的值。
