# 事后分析：余量、错配损失与标签可靠性（第 4 篇；2026-11-11 20:30 北京时间前写，先于下面任何读数）

**性质**：全部是看过各环境全部登记结果之后设计的，事后、探索性。写本文件时看过的：各环境的登记结果；跨环境的比例表（`posthoc/ratio_loss.md`，6 个点，比例 0.13–0.53）；τ² 的 H1 / H2 与 P1τ / P2τ。**没看过**：下面四项的任何读数。
脚本 `posthoc/headroom.py`；只读已有续跑，不用 GPU。池：ALFWorld-7B（out_ds_alfw）、ALFWorld-Llama（out_ds_alfw_l8）、WebShop-A（7B 部署）、WebShop-B（Llama 部署）、τ²（2B 子集，缺失按修订 5 记失败）。WebShop 用奖励（登记的主读数）。gridworld 是筛选过的自建池、数据格式不同，不做。

**共同的量**（每条失败轨迹；候选 = 该轨迹所有位置的替代分支；净收益 = 分支 − 同位置的原动作分支，都用执行者自己的续跑）
- 执行者的续跑固定分成前一半 S、后一半 E。a_self = S 上净收益最高的候选；a_other = 选择者前 5 次续跑上净收益最高的候选；并列取平均。
- 损失 = E 上 a_self 的净收益 − E 上 a_other 的净收益。选择的价值 pc = E 上 a_self − E 上全部候选的平均。
- **余量 h = S 上最高的净收益 − S 上全部候选的平均**（只用 S）。损失只在 E 上评价，所以 h 与损失不共用续跑噪声。
- S、E 对调再算一次，两个方向分别算统计量后取平均。区间：按轨迹重抽 5,000 次的 90% 区间（τ² 按任务）。
- 这是登记分析的简化重写（登记用 50 次随机划分与随机数流打破平局），先核对它与登记的均值接近。

**1. 补全比例表**：加上 ALFWorld 7B ← Llama（登记的 H1；原 analysis.json 里没有逐轨迹的行）。比例 = Σ损失 / Σpc。
**2. 环境内部：余量大的轨迹损失是否也大**。每个（池，选择者）：Spearman(h, 损失)；按 h 三等分的平均损失。
 - 读法：多数池为正且区间不含 0 → 第二句话有环境内部的证据；多数区间含 0 → 只保留跨环境的描述，写弱。
 - 已知的局限：没有余量的轨迹损失必然约为 0，所以正相关部分是定义使然；因此同时报告**余量最高三分之一轨迹内的比例**（损失 / pc），看比例本身是否随余量变。
**3. 各池的标签可重复率**（位置层面；G = 最好替代候选 − 原动作；门槛 0.20；WebShop 在奖励尺度上）
 - N0 = 一半里 G ≥ 0.20 的位置在另一半里 < 0.20 的比例；每半 3 次（从每半里抽 3 次，200 次平均）与每半取满。保留增益 = 一半选出的最好候选在另一半上的 G。另报原动作分支的平均成功率（或奖励）。执行者：各池的部署者；τ² 另算 4B。
 - 读法：若 N0 随"保留增益"单调下降（跨池），第三句话成立；τ² 上 2B 与 4B 的对比单独报告。
**4. 下游训练的可行性（ALFWorld-7B 池）**：标签 = 位置上最好替代候选，条件是选择者自己的续跑里 G ≥ 0.20。选择者：7B（10 次）、14B（20 次与前 10 次）、Llama（10 次）。
 - 报告：各自的标签数；与 7B 标签同位置的比例、同位置且同动作的比例；**这些标签在 7B 上的真实增益**（7B 自己的标签用 S 选 E 评，别人的用 7B 全部续跑）；增益 ≤ 0 的比例。
 - 读法（事先定）：若 14B 的标签与 7B 的"同位置同动作"≥ 80%，或两组标签在 7B 上的平均增益相差 < 0.10，下游训练大概率测不出差别，不建议做。
