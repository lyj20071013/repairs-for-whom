## 复现时发现的问题：原 A 层脚本把"G 恰好等于 0.20"判成不到门槛
- `stale_analyze.py` 用 `G >= 0.20` 直接比浮点数；0.6 − 0.4 这类差在浮点下是 0.19999999999999996，被判成 < 0.20。登记写的是"G ≥ 0.20"。τ² 的 `main_analyze.py` 有 EPS，不受影响。
- 影响（原集合）：按原脚本的比较方式能复现已报告的数（139 个位置；点过期 0.85 / 0.81 对已报告的 0.863 / 0.799；D_V −0.022 / −0.020 对 −0.019 / −0.019，差别来自并列打破）。按登记的写法（含等号）：142–145 个位置；点过期 0.82 / 0.78；D_V −0.010 / −0.029。
- 结论（点过期占主导、L ≈ 0、D_V 不为正）不变；论文里已写的 ALFWorld 数字是哪一种口径，需要用户定（见对话）。H1 的 L 本身不含门槛比较，但求平均的位置集合会变。

## B. 标签的不可重复率（只用 π0）
| | h = 3，γ = 0.20 | h 取满，γ = 0.20 | γ = 0.50（h 取满） |
|---|---|---|---|
| ALFWorld 原集合 | 0.076 | 0.042 [0.020, 0.068]（h = 5） | 0.100 |
| ALFWorld 无规划器流水线 | 0.160 | 0.120 [0.080, 0.165]（h = 5） | 0.102 |
| τ²（v3） | **0.499 [0.451, 0.555]** | 同左（h = 3） | 0.621 [0.553, 0.692] |
- τ² 的 0.499 与主实验报告的 N0 逐位相同。
- **同样每一半 3 次，ALFWorld 是 0.08–0.16，τ² 是 0.50** → τ² 的噪声底高主要不是续跑次数的问题，是环境的性质。提高门槛也没用：τ² 在 γ = 0.50 下反而是 0.62。
- 追加（看过曲线后加的）：一半选出的标签在另一半上的平均增益——ALFWorld +0.55 至 +0.73，τ² **+0.10**（γ = 0.50 时 +0.25）。π0 在这些位置上自己接手的成功率：ALFWorld 0.116，τ² 0.641。
- 读法：τ² 的位置来自 2B 的失败，4B 自己接手已有 64% 成功，单步修复能带来的真实增益很小，续跑噪声相对很大；"验证过的标签"大半是选出来的噪声。这与"π1 没有变"相容（**推测**：标签的真实增益约 +0.1，训练信号弱；现有数据不能检验因果）。
