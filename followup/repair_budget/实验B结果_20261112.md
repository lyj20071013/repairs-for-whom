# 实验 B 结果：不用规划器候选选标签训练的后继（S-np；2026-11-12 东京时间 19:30 写）

## 结构核对（看 reward 之前）
- 标签：558 个，自检两条在服务器上通过（否则不会生成训练文件）。与 S 的决策点重合 66%；目标是规划器动作（模型也提议过）的占 44%（S 是 89%）；标签续跑里的估计增益 0.61（S 是 0.95）；第 558 个点的估计增益是 0，即有一部分标签没有估计增益。
- 训练：两个种子各 1,116 行、无丢弃、140 步，损失 1.29 → 0.18 与 1.74 → 0.16。
- 续跑：两个模型各 14,660 次，缺 0、重复 0。耗时 3.6 与 3.9 小时。

## 与预测的对照
- N1 两个种子都确认、损失在 0.35–0.60 内、不高于同种子的 S（0.598 / 0.586）：**符合**。
- N2 确认、增益小于 S：符合；但种子 12 的 +0.094 低于预测区间（+0.15 至 +0.35）。
- 后继的偏好差含 0 或略为负、不低于 −0.10：符合（种子 11 的区间不含 0）。
- 反方向阳性对照两个种子都不过：**种子 11 不符**（下界 0.115，通过）。这个种子上原模型来选损失 0.054，约占选择价值的三分之一。
- 标签里规划器动作 0.25–0.5、与 S 重合 0.6–0.85：符合（0.44、0.66）。
- H1 不过期、H3 不划算：符合。

## 结论
不用规划器候选选标签训练的后继，同样是原模型的差评估者；"位置变了、动作没变"也照样成立。局限：评估用的候选集合里仍有规划器动作；S-np 的标签里仍有 44% 是模型也提议过的规划器动作。
