## 1. 做法
- 续跑数据不变（`ro_eval_ret.jsonl`、`ro_eval_air.jsonl`，π0 = 4B、π1 = 4B-S4r，k = 6）；修复候选只保留判为可执行的（`probe_analyze.py --adm`），自由选择不变。没有可执行修复候选的位置不进读数（v1 下 60 个评价位置都还有，预计不去掉位置）。
- **主分析用 v1**（探针原规则，`adm_eval_v1.jsonl`）；**v2 并列**（`adm_all_v2.jsonl`；评价位置上与 v1 只差 1 个候选：一个金标 `transfer_to_human_agents`）。
- 对照列 = 全部候选（即探针结果，`report_probe_s4r.json`）。区间：按任务成簇重抽 2,000 次，90%；标准误 = 重抽的标准差。

## 2. 判定标准（看结果之前写定）
1. **H2（点过期）**：只看可执行候选时，点过期率的点估计落在 **0.50–0.85 之外** → 触发：主实验登记里 H2 的预测区间按新数字重写，并注明 π0 值得修的位置数与标准误。落在区间内 → H2 的预测不变。
2. **H3（刷新）**：Q(只查位置) − Q(复用) **≤ 0 且其 90% 区间上界 < +0.05** → 触发：H3 的预测重新考虑。只变号、区间仍宽 → 记为"方向不确定"，H3 的预测不改。Q(只查位置) − Q(复用) 与 Q(全部重新验证) − Q(只查位置) 都报区间。
3. **必报读数（不作触发条件）**：π0 值得修、两边都值得修的位置数与比例，全部候选 / 只看可执行候选两列并排，直接作第 3 步功效计算的输入。
4. **只作描述**：L_both；"最好候选换了的比例"及其对照（同一模型两半各自选、结果不一致的比例）。

## 3. 事先写下的方向预测（两个方向都写）
- **正向**：先知金标的价值来自信息优势，训练后对 π1 同样有用，所以多半落在"两边都值得修"。去掉之后：π0 值得修的位置变少、点过期率上升、两边都值得修的位置变少、各 Q 下降。
- **反向**：去掉金标后，剩下的修复（4B 提议、可执行金标）更依赖策略本身，动作过期可能变大（L_both、"最好候选换了的比例"相对其对照上升）。
- 若结果与两者都不符，如实记下。

### 按第 2 节判定
1. **H2 未触发**：v1 点过期率 0.833，在 0.50–0.85 之内（离上界只差一个位置：10/12；v2 0.769）。H2 的预测区间不变。

### 与事先方向预测的对照
- **正向预测全部方向一致**：π0 值得修 16 → 12，点过期率 0.625 → 0.833，两边都值得修 6 → 2，各 Q 都下降。变化集中在 retail（两边都值得修 5 → 1），即探针里 retail"两边都值得修"的位置大多靠不可执行的候选（主要是先知金标）。
- **反向预测（动作过期变大）无法检验**：剩下 2 个位置，最好候选都没换。

### 对主实验的含义（推测部分已标出）
- **最重要的一点：功效。** 只看可执行候选时，"两边都值得修"的比例是 0.033（v1）/ 0.050（v2），低于设计稿功效计算里最低的一档（5%）。按 260 个池位置粗算只有约 9–13 个，达不到"约 25–30 个"的目标。第 3 步的功效计算要把比例档位下调（至少含 3%），并且要考虑主实验 π1 的标签更多、变化更大，这个比例可能更低（推测）。
- 点过期在只看可执行候选时更高（0.83），说明"点过期为主"的方向并不依赖先知金标。
- 刷新的 Q 差在只看可执行候选时没有方向（标准误约 0.12），探针在这一点上没有信息。

### 讨论：方法教训（2026-11-05 00:45 北京时间补；用户 11-05 要求写入）
- **先知候选会让点过期率偏低。** 全部候选时 retail 上两边都值得修的 5 个位置，只看可执行候选（v1）后只剩 1 个：它们的"值得修"大多靠不可执行的候选（主要是先知金标）。先知候选的价值来自部署时拿不到的信息，这种信息不会因为训练而失效，所以对 π1 照样有用，于是这些位置继续"两边都值得修"，点过期率被压低（全部候选 0.625 → 只看可执行 0.833）。写论文时作为方法教训：候选里混有先知动作时，测出的标签过期会偏小。
- **两边都值得修的比例 ≈ π0 值得修的比例 ×（1 − 点过期率）。** 训练对策略的作用越大，点过期率越高，能用来测动作过期的位置就越少；这是问题本身的性质。过期越以点过期为主，动作过期越难测，同时也越不重要（按动作刷新能挽回的价值有限）。主实验里 L_both 的"不足"写成预期内的结果。
- **随机候选在交叉拟合里是噪声。**（11-05 功效计算时看到，只用已有的探针读数）v2 去掉随机候选后，π0 值得修 13 → 17、两边都值得修 3 → 5：一半续跑里靠运气胜出的随机候选，在另一半上回落，拉低了交叉拟合的 G。这支持主实验去掉随机候选。
