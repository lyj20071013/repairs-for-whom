## 6. 读数与判定
### 6.1 记号与基本定义（与探针、A 层相同）
- 位置 j，修复候选集 C_j（主分析：v3 可执行；敏感性：v2）；p̂ = 成功率；两半 H1 = k 0–2、H2 = k 3–5。
- **点价值** G_π(j)：用一半在 C_j 中选最好候选，在另一半上算 p̂(该候选) − p̂(free)，交换两半取平均；G ≥ 0.20 为"值得修"。
- 对 π1ˣ，只用它所在折的位置。

### 6.2 主读数 H1：D_V 与成本对照
- **刷新方式**（在 π0 的标签集 w0 上；每个切分 s ∈ {H1, H2}，e 为另一半；都只用 π1 的续跑做决定、在 π1 的另一半上评价，free 的基线也取 π1 的同一半 e）：
  - 只查位置：若 p̂_π0(a0)（π0 全部 6 次）− p̂_π1,s(free) ≥ 0.20 则保留，动作沿用 π0 的最好修复 a0；
  - 全部重新验证：在 C_j 中用 π1 的 s 半选 b1；若 p̂_π1,s(b1) − p̂_π1,s(free) ≥ 0.20 则保留，动作换成 b1；
  - 价值：保留的标签记 p̂_π1,e(动作) − p̂_π1,e(free)，丢掉的记 0。
- **V**(方式, j) = 两个切分的价值的平均；**d_j = V(全部重新验证, j) − V(只查位置, j)**（逐位置配对，同一切分、同一半评价）。
- **D_V** = w0 中全部位置（两折合并）的 d_j 的**简单平均**，即按位置加权；等价于两折的估计按各自 w0 位置数加权平均。
- **区间**：按任务成簇的稳健标准误（CR1，簇 = 任务；两折的任务不重叠）；单侧 90% 上界 = D_V + t_{0.95, G−1} × SE，G = 至少有一个 w0 位置的任务数。描述用的双侧 90% 区间同样用 t。另报按任务成簇重抽 2,000 次（种子 0、按折分层）的百分位区间作对照。
- **判定（非劣效，读法之一）**：单侧上界 < **+0.05** → "重新验证动作不划算"；否则 → "判不出"，报告估计值与区间。
- **成本对照（同时报告，实测）**：每个 w0 位置上，全部重新验证需要的续跑分支数 = |C_j| + 1（候选 + free），只查位置 = 1（free）；报告两者之比的平均。结论按"重新验证动作每个标签多换回 D_V（区间），代价是 X 倍续跑"写。
- **预测**：
  - D_V 的点估计在 −0.03 至 +0.05 之间，最可能约 0 至 +0.03；探针（只看可执行候选、去随机候选）是 +0.039（17 个位置），说明真值贴近界线也是现实的可能。
  - 成本比约 3 倍（探针 π0 值得修位置平均 2.2 个可执行修复候选 + free = 3.2）；**A 层约 7 倍**（5 / 35.8 个分支）。
  - 功效（`design_compare_tau2.py`，两折共 800 个位置）：真值 0 时判"不划算"的概率 0.90（ICC 0、方差同探针）/ 0.64（ICC 0.3、方差 1.5 倍）；真值 +0.02 时 0.56 / 0.33。
  - **预期内的结果之一**：D_V 约 +0.04、上界超过 +0.05，即"判不出"。这时结论写成"重新验证动作约多换回 0.04 / 标签，代价约 3 倍续跑"。

### 6.3 H2：点过期
- 点过期率 = P(G_π1 < 0.20 | G_π0 ≥ 0.20)，两折合并（按位置），区间同第 6.2 节（双侧 90%，t）。
- **主估计**：上面交叉拟合的点过期率，照常报告（点估计与双侧 90% 区间）。它**不**拿来和噪声底比。
- **检验（同一算法比较）**：在每一半内部单独算 G（不交叉拟合）：G^h_π = max_{c∈C_j} p̂_π,h(c) − p̂_π,h(free)，h ∈ {H1, H2}；≥ 0.20 为该半"值得修"。
  - 噪声底 N0 = P(G^{h'}_π0 < 0.20 | G^h_π0 ≥ 0.20)，(h, h') 取 (H1, H2) 与 (H2, H1) 的平均（同一策略、两半之间的"点过期"）；
  - 对照 S1 = P(G^{h'}_π1 < 0.20 | G^h_π0 ≥ 0.20)，同样两种 (h, h') 取平均（π0 在一半值得修，π1 在另一半不值得修）；
  - 两者都在同一批位置、同样的 3 次 / 半上算，只差策略。检验量 Δ = S1 − N0，按任务成簇的稳健标准误，单侧 90% 下界 = Δ − t_{0.95, G−1} × SE（G 为参与计算的任务数）。
  - **判定**：下界 > 0 → "点过期高于噪声"；否则 → "未能与噪声区分"。
- **预测**：交叉拟合的点过期率 0.60–0.90（探针只看可执行候选：v1 0.83、v2 0.77）；Δ 的单侧下界 > 0。

### 6.4 R1：训练让策略变好
- 池上自由接手：π1 − π0（各折自己的位置，合并按位置），区间同上；端到端：π1ˣ − π0 在 X 折任务上（合并按对话），按任务成簇。
- **预测**：自由接手 +0.05 至 +0.15（探针 S4r，26 个标签：+0.092）；端到端 +0.00 至 +0.08。
- **R1 得到确认** = 池上自由接手 π1 − π0（合并）的单侧 90% 下界 > 0（t 临界值，按任务成簇）。
- 若 R1 没有得到确认，H1 / H2 照样报告，论文里写明"π1 相对 π0 的变化未得到确认"，并用漂移描述变化的大小。

### 6.4A H1 结论的保护条款（用户 11-05 加）
- H1 的"重新验证动作不划算"只有在 **π1 确实变了**时才作为结论。"变了" = 以下至少一条成立：
  1. 第 6.3 节的检验判"点过期高于噪声"（Δ 的单侧 90% 下界 > 0）；
  2. R1 得到确认（第 6.4 节）。
- 两条都不成立：H1 写成"π1 变化太小，不具判别力"，D_V 与成本对照只作描述，不下"不划算"的结论。
- 两折各自也按同样的条件判一次（描述）；合并的结论只看合并的条件。

### 6.5 次要读数：动作过期
- **L(j)**（同探针）：r̂_π1 = π1 用一半选出的最好候选，r̂_π0 = π0 用全部 6 次选出的最好候选，都在 π1 的另一半上评价，L = p̂_π1(r̂_π1) − p̂_π1(r̂_π0)，交换两半取平均。
- **L_w0** = w0 上 L 的平均，区间同第 6.2 节，**不设判定界**。同时报告分解：L_w0 = 点过期位置的比例 × L(点过期部分) + 两边都值得修的比例 × L_both。
- **L_both**（两边都值得修的位置上 L 的平均）只作描述；预计这类位置约 40–80 个（800 × 5–10%）；少于 15 个时写"不足"，这是预期内的结果（两边都值得修的比例 ≈ π0 值得修的比例 × (1 − 点过期率)）。
- 预测：L_w0 在 −0.03 至 +0.03（探针 +0.010）。

### 6.6 描述性读数
- 刷新的完整比较：复用 / 只查位置 / 查位置 + 查标签（只查位置之后，对保留的位置再用 π1 的 s 半跑 a0：p̂_π1,s(a0) − p̂_π1,s(free) ≥ 0.20 才保留）/ 全部重新验证，各自的 V、Q（保留标签的平均真实收益，与 A 层相同）、保留比例、每位置续跑分支数。
- "最好候选换了的比例"（两边都值得修的位置），对照：同一模型两半各自选、结果不一致的比例（π0、π1 各一）。
- 按候选来源（4B 提议 / 可执行金标 / 原动作兼提议）分开的 L 与"最好候选换了"。说明：池上候选按原样注入（金标是纯调用、4B 提议多带文字），格式随来源不同。
- 阈值 0.10 / 0.30 的敏感性（G 的门槛）；v2 修复候选集的敏感性。
- **两折各自的估计并列报告**（D_V、点过期率、L_w0、R1），并报告两折之差（描述，不检验）。
- 种子稳定性（A 折）：π1ᴬ 与 π1ᴬ#2 的点过期率、复用的价值（"π0 的最好修复"在两者下的 p̂ − p̂(free)）并列。

- 漂移：TV(π1, π0) 与噪声底 TV(π0#2, π0)，众数动作变化率；不带文字的工具调用比例。
