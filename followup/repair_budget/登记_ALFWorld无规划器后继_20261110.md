## 5. 读数与判定（`alfw_stale/np_analyze.py`；写本登记时已用 S_s11、S_s12 的数据跑通，逐位复现事后分析 A 的主设定）
定义全部沿用事后分析 A：γ = 0.20（**含等号**，EPS = 1e−9）；每一半 5 次（0–4 / 5–9）；并列打破 sha256("STALE-TIE|位置|动作")；区间 = 按轨迹重抽 2,000 次（种子 0）的 90% 百分位区间；**单侧 90% 界 = 第 10 / 90 百分位**。
**主设定 = 无规划器流水线的候选集合**（π0 值得修的位置 92 个，与 π1 无关，事先已知）。每个种子分别判定。

### 5.1 R1：π1 是否变了
自由选择成功率 π1 − π0（180 个位置）的单侧下界 > 0 → 确认。

### 5.2 H2：点过期是否超过同口径噪声底
N0（π0 两半）= 0.120（已知）；S1 把第二半换成 π1；Δ = S1 − N0 的单侧下界 > 0 → 确认。

### 5.3 保护条款
R1 与 H2 都未确认 → 该种子的 H1、H3 只作描述。

### 5.4 H1（主）：动作是否过期
L = π0 值得修的位置上，π1 自己（交叉拟合）选的候选减 π0 用前一半选的候选，在 π1 另一半上的成功率差（事后分析 A 的 "L"，即 A 层原脚本的定义）。
- 单侧上界 < +0.05 且下界 ≤ 0 → **不过期**；
- 下界 > 0 且上界 < +0.05 → **小的动作过期**；
- 下界 > 0 且上界 ≥ +0.05 → **动作过期**；
- 其余 → 不确定。
- 两个种子合并：都"不过期" → 不过期；任一"动作过期" → 动作过期；否则任一"小的动作过期" → 小的动作过期；其余不确定。
- **与 A 层登记的差别（事先说明）**：A 层用双侧写法（90% 区间完全落在 ±0.05 内）。本登记改成单侧，理由是 L < 0 表示 π0 的标签比 π1 自己选的还好，不是"过期"；双侧写法会把明显为负的 L 判成"不确定"。**写这条时已经看到**：在同一候选集合上，S_s12 的 L = −0.037 [−0.064, −0.010]，双侧写法判"不确定"、单侧写法判"不过期"。A 层的双侧写法照样报告。

### 5.5 H3：重新验证动作是否划算
D_V = V(全部重新验证) − V(只查位置)，标签集（π0 全部 10 次 G ≥ γ，104 个位置）。单侧上界 < +0.05 → **重新验证动作不划算**；否则不确定。D_V(标签) 与成本比照报。

### 5.6 描述（不下结论）
1. S-np − 同种子 S：自由选择、点过期率、L、D_V 的配对差（同一批位置，按轨迹配对重抽）。
2. 原集合、去掉全部规划器动作两种候选集合上的同样读数。
3. 第一步动作恰是该位置规划器动作的比例（B、S、S-np 等，各 20 个样本）与漂移 TV。
4. 剂量图（论文 Figure 2）加上 S-np 的两个点（自由选择增益、点过期率）。
5. L_both 与"最好候选相同"的比例（选择效应，只描述）。
