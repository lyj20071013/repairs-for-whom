# Original experiments

This directory contains localized experiment code and unchanged raw records. Start with the [repository README](../README.md), [data index](../docs/DATA_INDEX.md) and [reproduction guide](../docs/REPRODUCING.md). The current analysis plan is in [original analysis plan](../analysis_plan/论文方案.md). Historical runtime commands are in [LEGACY_USAGE.md](LEGACY_USAGE.md).

Source files and research outcomes are copied without implementation changes. SSH transfer tooling, machine-specific handover documents, logs, downloaded models and external corpora are excluded. The early `out/` workflow depends on pilot trajectory sources that are not bundled; its saved design/outcomes are retained. No completeness claim is made for every historical pilot.
