# 后果分析：gridworld 确认实验（34 条轨迹；探索性，登记见 论文方案.md 6.7）

## A. “该在哪一步修”的标签与 7B 部署标签的一致率

每条轨迹的标签 = 净收益最好的候选所在的位置；一致率 = 两种标签（并列时各自均匀随机取一个）指向同一位置的概率。括号内为轨迹 bootstrap 90% 区间。

**续跑（每边 5 次）**

| 标签来源 | 与 7B 标签一致的概率 |
|---|---|
| 7B 另外 5 次（噪声上限） | 0.66 [0.55, 0.78] |
| 14B 5 次 | 0.72 [0.63, 0.80] |
| flash 5 次 | 0.72 [0.63, 0.81] |

**不用续跑（对 7B 一折的标签）**

| 标签来源 | 与 7B 标签一致的概率 |
|---|---|
| 7B 另一折（噪声上限） | 0.86 [0.77, 0.94] |
| oracle 决定性步骤 | 0.81 [0.71, 0.90] |
| 7B 贪心 | 0.52 [0.42, 0.61] |
| flash 裁判 | 0.79 [0.68, 0.88] |
| 7B 自评裁判 | 0.34 [0.21, 0.46] |

## B. 用谁的续跑来打分，方法排名会怎样变

同一组选择方式；“7B 打分”= 部署时的真实收益，“14B / flash 打分”= 基准若用这些模型做反事实重放来评判修复。所有打分都与方法选择所用的数据不相交。表中为选中修复的平均净收益（括号内为排名）。

| 选择方式 | 7B 打分 | 14B 打分 | flash 打分 |
|---|---|---|---|
| CAR：最晚显著位置 | +0.668（1） | +0.868（2） | +0.929（4） |
| 本文方法 SL(1, 10) | +0.660（2） | +0.801（4） | +0.804（6） |
| 7B 部署 10 次 | +0.656（3） | +0.765（5） | +0.765（7） |

| flash 裁判（只读日志） | +0.601（5） | +0.715（8） | +0.712（8） |
| 7B 部署 3 次 | +0.553（6） | +0.692（9） | +0.675（9） |
